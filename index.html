03 — ENGINEERING

From official records to four decision-ready workbooks

Each contributor took government and institutional sources through the same seven stages, independently, to reach a clean Power BI-ready workbook.

01
🛰️

Collect

Each contributor researched their assigned states into a shared 29-tab workbook, pulling from PIB, DoF Handbook of Fisheries Statistics, CPCB, CGWB, APWRIMS, MPEDA, ICAR institutes and PMMSY records.

02
⇩

Ingest

Import state-wise and year-wise records from government portals and handbooks into a working Excel layer.

03
🧹

Clean

Handle missing states, blank readings, inconsistent state/UT naming and duplicate entries across years.

04
✓

Validate

Check production totals, water-quality readings against BIS limits, and utilization percentages against source formulas.

05
⚙

Transform

Standardize species names, state/region labels, units, risk scores and quality-status categories.

06
◈

Analyze

Generate production trends, sustainability risk scores, utilization rates and water-quality compliance status.

07
▦

Visualize

Deliver four independent Power BI dashboards — one per contributor, one per data model.

06 — SETUP

Run it yourself

Open the website locally, then open any dashboard in Power BI Desktop.

1

Open the website

Extract this folder and double-click index.html — no server or build step needed.

2

Pick a dashboard

Go to Live Reports, choose a module, and download its .pbix package.

3

Extract if zipped

Three of the four packages are zipped — extract them first to get the underlying .pbix file.

4

Open in Power BI Desktop

Double-click the .pbix file. Power BI Desktop is free from Microsoft if not already installed.

5

Optional: publish for a live embed

Publish the report to Power BI, then replace a module's preview panel with an <iframe> using that report's embed URL. 

<iframe src="YOUR_EMBED_URL" width="100%" height="480"></iframe>

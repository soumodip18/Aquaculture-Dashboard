# AQUABAS — India Aquaculture & Water Intelligence Dashboard

AQUABAS is a centralized dashboard platform for aquaculture intelligence and water-resource monitoring in India. The project brings together multiple Power BI-driven analytical views into a single, accessible web experience for exploring aquaculture production, species trends, inland water systems, and water quality insights.

This project is designed to support better decision-making for agribusiness, research, and sustainable aquaculture planning by presenting key indicators in a clear, visual, and user-friendly format.

---

## Overview

India’s aquaculture sector depends on a range of interconnected factors, including:
- fish and shrimp production
- species distribution and farming practices
- inland water resources
- water quality monitoring
- sustainability and risk assessment

AQUABAS consolidates these areas into a unified dashboard framework, helping stakeholders understand how environmental and production variables interact across regions and systems.

---

## Objectives

The main goals of this project are to:
- provide a single entry point for multiple aquaculture dashboards
- visualize aquaculture and water intelligence across Indian geographies
- monitor water quality and resource conditions
- identify trends in species performance and production
- support evidence-based planning and sustainable operations
- present data in a simple, dashboard-friendly format for quick interpretation

## Deployment

This project is structured as a static web page and is suitable for deployment on GitHub Pages.

### Run locally
Open `index.html` directly in a browser, or serve it with a local web server if needed.

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
